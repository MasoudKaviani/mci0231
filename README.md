# پروژه عملی ۰۷: اتوماسیون پایپ‌لاین CI/CD با GitHub Actions

این فایل و ساختار نمونه نشان می‌دهد چگونه فرایند ساخت ایمیج‌های داکر را برای دو معماری سخت‌افزاری `linux/amd64` و `linux/arm64` به صورت کاملاً خودکار و پیوسته به همراه لایه کشینگ پیشرفته پیاده‌سازی کنید.

---

## 🔑 تنظیم پیش‌نیازها در گیت‌هاب

۱. در ریپازیتوری گیت‌هاب خود به بخش **Settings > Secrets and variables > Actions** بروید.
۲. دو سکرت زیر را ایجاد کنید:
   - `DOCKERHUB_USERNAME`: نام کاربری شما در داکر هاب
   - `DOCKERHUB_TOKEN`: یک Personal Access Token (PAT) ساخته‌شده در Docker Hub (از رمز عبور اصلی استفاده نکنید!)

---

## ⚡ نکات کلیدی در این پایپ‌لاین:
- **پشتیبانی همزمان از چند معماری (Multi-Arch):** با استفاده از اکشن‌های QEMU و Buildx، ایمیج هم برای سرورهای اینتل/AMD و هم برای سرورهای ARM (مثل Mac M1/M2/M3 یا سرورهای AWS Graviton) تولید می‌شود.
- **کشینگ لایه‌ای گیت‌هاب (`cache-from: type=gha`):** سرعت بیلد تا ۱۰ برابر افزایش می‌یابد.
- **برچسب‌گذاری هوشمند:** با هر Release یا کامیت، تگ‌های مناسب (نسخه SemVer یا هش کامیت) به ایمیج اختصاص می‌یابد.
